Lead Radar 3.3 作品/评论监控增强
- 监控默认使用可见浏览器（MONITOR_HEADLESS=0）；检测登录/验证页并等待人工完成，不绕过。
- 修复 B站评论读取为 0（Shadow DOM），新增评论 ID、发布时间、#reply 直达链接。
- 修复 B站 /zh-Hans/ 等语言前缀链接被误判无效。
- 按规范化地址去重（去掉小红书 xsec_token 等），旧数据自动迁移，解决每轮重复入库。
- 小红书优先使用带 xsec_token 的作品链接；搜索卡片只取有效作品地址、可见标题。
- 默认最新发布优先排序；不支持时回退综合排序。
- 新增作品点赞/收藏/评论/分享/投币/播放数，监控时刷新；API 来源同样保存计数。
- 新增作者主页链接与「关键词相关用户」汇总（/api/authors、/api/authors.csv）。
- 评论按滚动累积读取，每作品最多 30 条；每平台最多 20 条作品。
- 所有浏览器平台评论都可尝试高亮定位（含已有直达链接的）。
- 纯接口监控不再被浏览器锁阻塞；调度不再被等待浏览器的任务卡住；异常后不会卡在“正在采集”。
- 修复：手动保存非小红书/抖音链接 500 错误；Reddit/GitHub 单帖评论失败丢弃整批；国内 Bing 跳转 cn.bing.com 报错；HN 文本 HTML 实体未解码；未安装 Playwright/Docker 时浏览器平台误显示可用。
- 测试 74 → 109 项；B站在真实网站上端到端验证；其余需登录平台未用真实账号验收。
- 控制台重新设计：4 个标签页（搜索与监控 / 线索 / 相关用户 / 工具与设置），首页按「登录 → 关键词和平台 → 监控任务」三步操作。
- 新增「打开浏览器去登录」（/api/browser-login）和「立即搜索一次」（/api/search-now，浏览器平台与公开接口一起搜，带逐平台进度）。
- 线索支持按平台、作品/评论筛选（/api/platforms）；旧数据里的 HTML 实体自动解码。
- 一键启动：只需双击 start.bat。自动安装 Python 3.12（缺少时）、依赖、Chromium（国内镜像兜底，再不行用系统自带的 Edge/Chrome），创建桌面快捷方式，启动服务并打开网页；已在运行时直接打开网页。启动日志写入 data/start.log。
- 代理/VPN 兼容：采集浏览器检测到系统代理时，国内平台（抖音、小红书、微博、知乎、B站、快手、贴吧及其 CDN）直连，境外网站走代理，修复全局代理下抖音 ERR_CONNECTION_CLOSED；.env 可设 BROWSER_PROXY=auto/direct/system/代理地址。
- 网络错误改为中文原因和处理办法（连接被中断、代理连不上、超时、证书拦截等），登录页打不开时在页面上标红提示。
- 新增「网络诊断」（/api/network-check）：域名解析（识别 TUN/Fake-IP）、直连、走系统代理、采集浏览器实际访问逐项检查并给出结论；可复制诊断结果。
- start.bat 识别端口上的程序是否为本文件夹的最新代码（/api/health 返回 build 指纹和目录）；旧版本或其他文件夹的程序会被自动关闭后再启动新版，避免“换了新包却还在跑旧代码”。
- 网络方式自动选择：登录、搜索、定位评论前，用真实页面测试并自动在「国内直连+境外代理 / 不走代理 / 全部走系统代理 / 系统 Edge」之间切换，记住可用的方式（data/network_route.json）；网络诊断显示每种方式能否打开抖音。
- 内置直连通道（app/relay.py）：本机 127.0.0.1 上的小型 CONNECT 代理，用公共 DNS（223.5.5.5 / 119.29.29.29）解析后直连，绕开关闭 TUN 后残留的 198.18.x.x 假地址和系统代理；检测到系统 DNS 返回假地址时优先使用。
- 网络诊断区分「虚拟网卡仍在运行（列出网卡名）」「网卡 DNS 残留」「DNS 缓存残留」，新增公共 DNS 对比和「清除 DNS 缓存」按钮（/api/network-fix）。
- 修复：自动选择网络方式时只测试第一个平台（小红书能开就不再尝试其他方式，导致抖音一直打不开）。现在每种方式都会逐个测试所选的全部平台，全部能开才采用；都不行时选打开最多的一种，并列出仍打不开的网址。
