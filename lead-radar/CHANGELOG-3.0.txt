Lead Radar 3.0 主要更新
1. 公开数据源新增 Bluesky，YouTube 正式视频与少量顶层评论，GitHub/Reddit 公开评论的受限轮询。
2. 浏览器公开网页采集尝试扩展至微博、知乎、B站、快手、TikTok、百度贴吧。
3. 持续监控支持浏览器+公开来源+已配置的授权 JSON 混合平台。
4. 动态状态面板将未授权平台标为“需配置”，每来源独立报告错误。
5. Windows 启动改为独立 run-server.bat，避免路径带空格被识别为无效命令。
6. API 与测试覆盖增加。
说明：未在真实平台账号或 Windows 实机完成验收；不保证全站采集或访问所有评论。
