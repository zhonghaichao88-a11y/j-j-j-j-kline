# Lead Radar 4.0 · 全网关键词获客 · 买家识别 · 跟进管理

## 4.0 更新要点（先看这里）

**一句话**：输入关键词，程序在 8 个国内社交平台 + 十多个公开网站/社区/政府采购网上找「正在问、正在找、正在买」的人，自动把**买家需求**排在前面、把**同行广告**压下去，然后帮你提醒跟进、套用话术、统计转化。

**使用方法和 3.3 一样**：双击 `start.bat` → 登录平台 → 输入关键词 → 「立即搜索一次」或「开启持续监控」→ 到「线索」跟进。从 3.x 升级：把旧目录的 `data/` 整个复制过来，启动后自动迁移，旧线索按新规则重新打分，跟进状态和备注保留。

### 能从哪里找客户

| 类别 | 来源 | 需要什么 |
|---|---|---|
| 国内社交（浏览器采集） | 小红书、抖音、微博、知乎、B站、快手、百度贴吧、TikTok：作品 + 评论 + 互动数 | 在弹出的浏览器里登录一次 |
| **B2B 采购（新）** | **中国政府采购网**：最近 30 天的招标/询价/采购公告，采购人就是要买东西的单位，直接判为高意向 | 无；网站限频，监控间隔建议 3 小时以上 |
| **中文社区（新）** | **V2EX**（程序员、独立开发者、创业者，常见「求推荐 XX 工具/服务」） | 无 |
| **英文问答（新）** | **Stack Overflow / Software Recommendations / Web Apps**（「有没有好用的 XX 软件」） | 无（每天约 300 次；填 `STACKEXCHANGE_KEY` 更多） |
| 英文社交/社区 | Bluesky（已修复）、**Lemmy（新）**、**Mastodon（新）**、Hacker News、GitHub Issues、Reddit | Reddit 需填免费的 `REDDIT_CLIENT_ID/SECRET` |
| 论坛（新） | 任意 **Discourse** 论坛（很多 SaaS/行业社区用它） | 在 `.env` 填 `DISCOURSE_SITES` |
| 视频/官方 API | YouTube、X(Twitter) | API 密钥 |
| 授权数据接口 | Instagram、Facebook、LinkedIn、Telegram 等 | 你自己有授权的数据服务商接口 |

每个来源都在 2026-10 实际联网测试过（政府采购网对境外服务器限频，解析逻辑用页面样本测试）。**说明**：Reddit 从 2023 年起基本禁止未登录访问，Bluesky 原来的公开搜索地址已返回 403，所以 3.3 里这两个来源其实一直拿不到数据，4.0 已修复。

### 找得更准：买家 / 商家 / 提问 自动区分

关键词搜出来的内容，很多是**同行在打广告**。4.0 给每条内容判断类型并说明理由：

- **买家需求**（高分）：求推荐、多少钱、哪家好、有人能做吗、想找供应商、有预算、评论区「dd / 蹲 / 求链接」、looking for a … tool、any recommendations…
- **商家广告**（降分，默认不显示）：欢迎咨询、加微信、承接、招代理、限时优惠、软文测评（「深度解析」「附避坑清单」）、英文营销话术、话题标签堆砌、招聘信息
- **提问咨询**（中分）：好用吗、怎么选、有没有人用过…

卡片上直接显示打分依据（绿色 = 加分，红色 = 降分）。在「⚙️ 工具与设置 → 🎯 意向规则与过滤」里可以加你们行业自己的买家词和广告词、全局排除词、屏蔽同行账号，保存后所有已有线索自动重新打分。

### 跟进更顺手

- **首页概览**：24 小时新增、高意向、未跟进的高意向、**跟进到期**，加 14 天趋势和跟进漏斗，点数字直接跳到对应线索。
- **跟进提醒**：每条线索可设「3 小时后 / 明天 / 3 天后 / 1 周后」提醒，到期标红并计数。
- **话术库**：点「💬 话术」选模板，自动填入对方昵称、关键词、标题并复制，去平台里粘贴发送（**程序不会自动评论/私信**，那样会被平台封号）。
- **批量操作**：多选后批量改状态、设提醒、加标签、删除。
- **🚫 屏蔽**：同行或广告号一键屏蔽，以后不再收录。
- **筛选 + 导出**：按类型、时间、提醒、标签筛选，按高意向/最新/发布时间/跟进时间排序；「导出 CSV」按当前筛选导出。
- **监控任务可修改**，支持排除词（例如排除「招聘、兼职、课程」）。
- **新线索推送到企业微信 / 钉钉 / 飞书群**：在 `.env` 填 `ALERT_WEBHOOK_URL`，自动识别格式；「工具与设置 → 🔔 新线索通知」可发测试消息。

### 仍然做不到的（平台不公开）

看不到「搜索过关键词的人」、点赞/收藏用户名单、私信、手机号；不绕过登录和验证码；浏览器采集不保证全量，平台改版后选择器可能需要更新。意向分是透明的关键词规则，不是购买概率。

## 3.3 更新要点


**怎么用（Windows）**：
1. **解压 ZIP 后双击 `start.bat`，只需要这一个。** 第一次会全自动完成（约 3-10 分钟，看网速）：
   - 没有 Python 3.11+ 就自动下载安装 Python 3.12，只装给当前用户，不用管理员权限；官网下载失败会换国内镜像；
   - 自动创建运行环境、安装依赖（失败自动换清华镜像）；
   - 自动安装浏览器组件 Chromium（失败自动换国内镜像；仍失败就用电脑自带的 Edge 浏览器）；
   - 在桌面创建「Lead Radar」快捷方式，启动服务（最小化的「Lead Radar Server」窗口，关掉它程序就停止），并自动打开网页。

   以后双击桌面上的「Lead Radar」即可，几秒就能打开；程序已经在运行时双击会直接打开网页。启动过程记录在 `data/start.log`，出问题时把它发给技术人员。`install-browser.bat` 只用来修复浏览器组件，平时不用点。
2. 控制台打开后，默认在「🔍 搜索与监控」页，按页面上的 3 步操作：
   - **① 登录平台**：勾选要用的平台，点「打开浏览器去登录」，在弹出的浏览器里逐个标签页扫码登录，完成后关掉浏览器窗口。只需做一次，登录状态保存在 `data/browser_profile/`。
   - **② 输入关键词、勾选平台**：点「立即搜索一次」马上搜；点「开启持续监控」以后自动定时搜。排序、数量、间隔在「高级选项」里。
   - **③ 我的持续监控**：查看每个任务的状态、下次检查时间、新增数量和失败原因。
3. 「📋 线索」看结果：可以按平台、作品/评论、意向、跟进状态筛选；评论可以打开直达链接或「尝试高亮评论」。
4. 「👥 相关用户」看发帖、评论的用户汇总；「⚙️ 工具与设置」里是使用说明、手动保存链接、授权接口、关键词组和采集记录。

**做不到的（平台不公开，任何合法方式都拿不到）**：
- “搜索过某个关键词的用户”：平台从不公开别人的搜索记录。本程序给出的是**公开发作品、发评论的人**。
- “点赞/收藏了某作品的用户名单”：不公开，只能拿到数量。
- 不会绕过验证码、伪造指纹、读取私信或手机号。各平台的反爬策略随时会变，浏览器采集**不保证每轮都成功、也不保证全量**；监控太频繁可能触发平台风控，账号风险由使用者自行承担。

**3.3 实测情况（构建环境，海外服务器 IP、未登录任何账号）**：
- B站：真实跑通搜索（最新排序）、作品互动数、作者主页、评论（含 ID、时间）、`#reply` 直达和高亮定位。
- 小红书、抖音、微博、知乎、贴吧：都正确识别为登录/验证页，并提示人工处理。
- 快手、TikTok：当前网络下没有返回结果。

以上 5 个需要登录的平台没有账号实测，选择器以平台当前公开页面结构为准，改版后可能需要更新。

**关了虚拟网卡还是打不开？** 常见原因是 Windows 的 DNS 缓存或网卡 DNS 设置里，还留着代理软件的假地址（198.18.x.x）。网络诊断会分别显示「运行中的虚拟网卡」和「网卡 DNS」：前者说明代理软件的服务模式还在运行，需要从托盘彻底退出；后者点「🧹 清除 DNS 缓存」，或把网卡 DNS 改回自动。在这之前，程序会自动改用**内置直连通道**：用阿里、腾讯的公共 DNS 查真实地址，再直接连接，绕开 DNS 残留。

**开着代理/VPN 也能用**：采集浏览器打开平台前会自动尝试几种网络方式，用第一个能打开的，并且记住，下次直接用。依次是：国内直连、境外走代理 → 完全不走代理 → 全部走系统代理 → 程序内置直连通道（公共 DNS）→ 换电脑自带的 Edge 再试一遍。不需要你手动切换。只有代理软件开着 **TUN/虚拟网卡模式**、并且把国内网站也转发出去时，所有方式都会失败，这时需要在代理软件里关掉 TUN，或改成规则模式。

**抖音、小红书打不开？先点首页的「🩺 打不开？网络诊断」**。它会逐个检查域名解析、直连、走代理、采集浏览器访问，直接给出结论（例如代理开着 TUN 模式、杀毒软件在拦截 HTTPS、需要改 BROWSER_PROXY），还能一键复制诊断结果发给技术人员。

**开了代理/VPN 后抖音、小红书打不开（ERR_CONNECTION_CLOSED）？** 原因是代理在全局模式下，把国内网站也绕到了国外节点。现在程序默认 `BROWSER_PROXY=auto`：检测到系统代理时，采集浏览器访问国内平台直接连接，TikTok 等境外网站继续走代理。如果还是打不开：
1. 把代理软件切到「规则模式」，或暂时关掉代理；
2. 如果代理软件开了 **TUN/虚拟网卡模式**，请关掉，这一层浏览器设置管不到；
3. 也可以在 `.env` 里写 `BROWSER_PROXY=direct`（完全不用代理），改完重启程序。

**新增 .env 选项**：`MONITOR_HEADLESS=0`（1=无头后台，不建议）、`MONITOR_LOGIN_WAIT_SECONDS=60`、`BROWSER_PROXY=auto`（auto/direct/system/代理地址）。

**3.2 → 3.3 升级**：关闭旧版，把旧目录的 `data/` 整个复制到新目录（包含数据库和浏览器登录状态），启动新版会自动迁移，跟进状态和备注保留。

## Windows 安装使用

1. **完整解压** ZIP 到一个新文件夹，例如 `D:\LeadRadar`。不要在压缩软件里直接运行。
2. 双击 **`start.bat`**，按上面「怎么用」的说明等待自动安装完成，网页会自动打开。
3. 点 `stop.bat`，或关闭「Lead Radar Server」窗口，可以停止程序。旧数据迁移：把旧目录的 `data/` 整个复制到新目录。**不要把 `data/browser_profile/` 发给别人，里面有你的登录状态。**
4. 想用 Docker：在项目目录运行 `docker compose up -d`。Docker 版不支持社交平台的浏览器采集。

### Windows “不是内部或外部命令”

本版 `start.bat` 与 `stop.bat` 均为 Windows CRLF；并新增独立 **`run-server.bat`**（只在启动时由 `start.bat` 调用）。请确保 ZIP **三个 BAT 文件都在项目根目录**，不要只复制一个启动脚本。启动失败会保留报错黑窗口。电脑必须有 Python 3.11+，并能连接 `pip` 安装依赖。所有平台的外网搜索也需要你的电脑能访问对应网站。

### 不购买第三方 API 可以做什么？

试用浏览器可见公开搜索、GitHub、Hacker News、Bluesky、Reddit 和新闻 RSS。公开访问不代表无限免费或永远可用。**YouTube 的官方视频/评论查询需要 Google API Key**；其他商业社交平台大规模、稳定监测通常需要明确的访问权限。

## 监控与接口

- `GET /api/monitor-sources`：列出每个平台的 `mode`、`configured`、`note`，不会把未接入误标为可用。
- `POST /api/monitors`：`{"query":"GPT","platforms":["xhs","douyin","bluesky","hackernews"],"interval_minutes":10,"max_posts":8,"max_comments":10}`。
- `GET /api/monitors`：查看任务状态、新增数、失败原因、下次执行时间。
- `GET /api/monitor-runs`：每轮按平台报告获取数量、新增量和错误。
- `POST /api/search-online`：手动在线搜索，支持 `googlenews,bingnews,github,hackernews,reddit,bluesky,youtube`（YouTube 需要密钥）。注意普通在线搜索不自动读取 YouTube/GitHub/Reddit 评论；**这些评论由持续监控任务按配额读取**。
- `POST /api/browser-crawl/start`：本机交互式浏览器采集；需要 Playwright。
- `GET /api/items`：数据库筛选；`GET /api/export.csv` 导出；原文链接在结果中点击。
- 其他沿用 2.4 已有的关键词管理、跟进、备注、状态、CSV、授权 JSON 等接口。自动评分只是简单关键词规则，不是客户购买意图概率。

### 接入自有授权 JSON 供应商

复制 `.env.example` 为 `.env`（首次启动自动创建），填写如 `INSTAGRAM_API_URL=https://provider.example/authorized-search` 和可选 `INSTAGRAM_API_TOKEN=...`。接口需返回 `{"data":[{"title":"...","text":"...","url":"https://...","author":"...","published_at":"..."}]}` 等支持的 JSON 结构。程序不会自行获得供应商账号/授权。修改 `.env` 后重启程序。可选本地 SQLite 或自行配置 PostgreSQL。

**提示**：运行程序不等于完成商业授权，也不等于可以访问任何第三方平台的非公开搜索、评论或用户历史。

## 3.1 评论跳转 / 辅助定位（2026-10-23）

原 3.0 的 `#lr-comment-xxx` 只是本地去重标记，不是网站支持的评论直达链接。3.1 已去除将它误当作用户可点击直达链接的行为，并向旧数据库追加元数据字段、自动修复旧记录（不删除历史数据或跟进备注）。

在控制台「线索列表」里：
- **打开评论**：仅在来源提供评论本身的网址时出现，例如 GitHub 评论、Reddit 评论、YouTube 公开评论链接，以及页面确实带有明确评论参数的链接。实际落点由第三方平台决定，不保证任何时候精准定位。
- **打开所属作品**：小红书、抖音、快手、微博、知乎、B站等未提供真实直达网址的评论，只打开视频或笔记原文，不伪造链接。
- **尝试高亮评论**：仅针对受支持的浏览器采集评论，在**运行本程序的本机**启动 Playwright Chromium，利用本人已登录的浏览器会话访问所属作品，并在已渲染、可见的评论区内做有限滚动搜索与高亮。一次最多尝试约 12 次滚动。找到后浏览器最多保留约 90 秒供查看/回复；浏览器关闭后恢复正常调度。未找到时会显示原因，并保留原作品链接和「复制评论文字」按钮。监控或采集占用浏览器时需结束当前任务后再试。
- **复制评论文字**：复制公开昵称与评论内容，方便手动查找。

### 使用条件和限制

1. （3.3 起只需双击 `start.bat`，会自动安装 Python、依赖和浏览器组件。）启动和浏览器安装并非在所有 Windows 环境完成实机验证。
2. 使用本人已登录、可正常访问的平台页面；遇到验证码或登录，请手动处理。程序不绕过验证，不读取未授权数据。
3. 评论被删除、折叠、折叠进回复、排序变化、页面加载失败或平台改版时，辅助定位可能失败；这不等于平台支持了永久直达链接。
4. 3.1 的单元测试与本地 HTTP 测试均不能证明第三方平台真实可采集或精准定位；上线前须在用户自己的电脑逐平台实测。
5. 如果要迁移原来的历史数据，先备份旧版 `data/lead_radar.db`，将旧数据库文件及相应 SQLite WAL/SHM 文件（关闭旧程序后）复制到新版同名 `data/` 目录，然后启动新版自动迁移。不要把两个版本同时运行在端口 8000。

## 3.2 多平台评论导航增强（2026-10-23）

本次**在 3.1 原有业务功能上增量修改**，没有删除原始监控、关键词、数据库记录、线索跟进和授权入口。

- **小红书、抖音、微博、知乎、B站、快手、TikTok、百度贴吧（共 8 个可见浏览器采集平台）**：按平台 DOM 选择器尝试读取公开可见评论，保存作品地址、可见评论 ID（如果网页提供）、评论内容、作者。点击「尝试高亮评论」时，优先匹配 ID，也可以按可见文字、作者查找，并尝试滚动对应的评论容器。依然依赖平台当前页面、用户本人登录及网页可见性。
- **Reddit、GitHub、YouTube、Hacker News、Bluesky**：对于公开 API 确实给出的**评论或回复原文链接**，保存明确的直达链接；YouTube 仍需官方 API Key，Reddit/GitHub 等可能有配额或访问限制。
- **Instagram、Facebook、Threads、Telegram、LinkedIn、Pinterest 等需授权的平台**：如果你的授权 JSON 接口返回评论记录，则保存评论与所属作品链接。**没有被校验为评论直达链接的地址，标注为「手动查找」而不是虚构可以精准跳转。**这些平台不是自动全站抓取服务，未配置接口时不能使用。
- 原版的 `#lr-comment-...` **只允许用作本地去重令牌**，不再作为用户点击的目标地址。旧 SQLite 表的现有线索 ID、跟进备注和状态不受此次升级影响。
- 修复采集状态面板过去把所有平台显示成“小红书/抖音”的问题，并将所有评论来源加入列表过滤选项。
- Windows 启动 `start.bat` 与 `start.ps1` 的版本检测已同步修改至 `3.2.0`，防止启动新版后被误判为没有启动成功。

**重要限制**：没有任何合法通用方法能保证所有平台每条评论都能直接定位；真实网站可能折叠、删除、禁止评论查看、要求登录或改版。此次本地 74 项单元与模拟接口测试、JavaScript 语法检查不是在真实账号上逐个平台验收。请先在你自己的 Windows 电脑、合法可访问的页面上运行至少一轮，再根据页面具体的失败提示排查；不能承诺“抓全网”。

**授权接口 JSON 评论示例：**

```json
{"data":[{"type":"comment","content":"请问 GPT 客服怎么购买？","author":"公开用户","post_url":"https://www.douyin.com/video/123456","comment_id":"9876","comment_url":"https://www.douyin.com/video/123456?comment_id=9876"}]}
```

只有 URL 来自获授权的数据源、校验为平台同源并携带可识别的评论定位信息时，才显示评论直达按钮。即使如此也可能被平台重定向到作品页；以平台实际行为为准。
