📖 使用说明

基本流程：①「搜索与监控」里先点「打开浏览器去登录」登录一次 → ② 输入关键词、勾选平台 →「立即搜索一次」或「开启持续监控」→ ③ 到「线索」查看、跟进。

搜不到东西？看「搜索进度」或监控任务下的红字原因。常见原因：没登录或登录过期（重新点「打开浏览器去登录」）、出现验证码（在弹出的浏览器里手动完成）、关键词太偏。

线索怎么看：绿色标签「买家需求」是有人在求推荐、问价格、找供应商，优先跟进；灰色划线「商家广告」是同行在打广告，默认不显示（筛选里可以查看）；每条下面的小标签是打分依据。首页「概览」的数字可以直接点。

怎么跟进：「💬 话术」复制回复模板 → 去平台里发送 → 状态改「已联系」→ 设「⏰ 提醒」，到期会在首页「跟进到期」里提醒你。同行账号点「🚫 屏蔽」。

能拿到什么：公开作品、作品的点赞/收藏/评论/分享数、可见评论、作者和评论者的昵称与主页。拿不到：别人的搜索记录、点赞/收藏用户名单、私信、手机号。

注意：监控间隔太短可能触发平台风控，建议 15 分钟以上；程序和电脑要一直开着。

🎯 意向规则与过滤

程序按规则给每条内容打分：「求推荐 / 多少钱 / 哪家好 / 有人能做吗」等是买家；「欢迎咨询 / 加微信 / 承接 / 招代理」等是商家广告，会被降分。下面可以加上你们行业自己的词，保存后已有线索会重新打分。每行一个或用逗号隔开。

💬 话术库（回复模板）

线索卡片上点「💬 话术」选一条，会自动替换变量并复制，粘贴到平台里回复即可。变量：{author} 对方昵称、{keyword} 命中关键词、{title} 作品标题、{platform} 平台名。请人工发送，程序不会自动评论或私信（平台会封号）。

🔔 新线索通知（企业微信 / 钉钉 / 飞书）

发现高意向线索时，自动推送到你的群机器人。在程序文件夹的 .env 里填写 ALERT_WEBHOOK_URL=，重启程序：

  • 企业微信：群 → 添加群机器人 → 复制 Webhook 地址（https://qyapi.weixin.qq.com/…）
  • 钉钉：群设置 → 机器人 → 自定义 → 安全设置选「自定义关键词」，填 Lead Radar
  • 飞书：群设置 → 群机器人 → 自定义机器人
  • 微信个人：用 Server酱（sctapi.ftqq.com）的发送地址
  • 也支持 Slack、Discord 和任意接收 JSON 的地址
🌐 数据来源说明与密钥配置

不用配置就能用：小红书、抖音、微博、知乎、B站、快手、贴吧、TikTok（浏览器采集，需登录）；V2EX、中国政府采购网、Hacker News、GitHub、Bluesky、Stack Overflow、Lemmy、Mastodon（按话题标签）、Google/Bing 新闻。

填了 .env 更好用：

  • REDDIT_CLIENT_ID / REDDIT_CLIENT_SECRET：Reddit 现在基本禁止未登录访问。到 reddit.com/prefs/apps 免费建一个 script 应用即可
  • YOUTUBE_API_KEY：YouTube 视频和评论（Google Cloud 免费额度）
  • X_BEARER_TOKEN：X(Twitter) 官方 API
  • GITHUB_API_TOKEN：GitHub 搜索额度从每分钟 10 次提高到 30 次
  • DISCOURSE_SITES：要监控的 Discourse 论坛域名，逗号隔开
  • MASTODON_ACCESS_TOKEN：Mastodon 全文搜索（不填只能按 #话题）
  • STACKEXCHANGE_SITES / STACKEXCHANGE_KEY：选择 Stack Exchange 站点、提高额度
  • INSTAGRAM_API_URL 等：你自己有授权的数据服务商接口

政府采购公告是 B2B 最直接的买家信号（采购人就是要买东西的单位），但该网站限制访问频率，建议监控间隔 3 小时以上。
